# SchoolNation

아이들과 함께 학급의 약속과 경제를 운영하는 반응형 웹앱입니다. ClassBud에서 기능 아이디어만 참고했으며, 화면 이름과 구성, 색상, 문구는 독립적으로 만들었습니다. 플랫폼 요금제·구독·결제 기능은 범위에 넣지 않았습니다.

## 지금 실행되는 것

- 반응형 교사 대시보드와 학급 홈
- 학생 타일, 모둠 필터, 검색, 예시 학생 추가
- 예시 계좌 잔액과 보상 거래 기록
- 학급 상점 구매 체험 및 재고 표시
- 학급 기능 토글과 학급명/화폐명 변경
- 활동 기록, 오후 8시 예약 작업 상태 화면
- 예시 데이터는 모두 가짜이며 브라우저 localStorage에만 저장

이 저장소의 첫 단계는 클릭해 볼 수 있는 UI 데모와 데이터베이스 보안 기반입니다. 로그인 버튼 전환, 예시 거래, 예시 데이터는 데모용입니다. 실제 사용자 인증/초대, 계정 복구, DB 읽기 화면 연결은 실제 학급 데이터를 받기 전에 다음 구현 단계에서 연결해야 합니다. 배포 전에는 SQL 마이그레이션을 적용하고 인증 연결을 확인하세요.

## 기술 선택

- Next.js 16 App Router + TypeScript: 한 프로젝트에 화면과 서버 기능을 둘 수 있습니다.
- Supabase Postgres + Auth/RLS: 관계형 거래 원장, 원자적 DB 함수, 행 단위 권한에 적합합니다.
- 비용 절감: 화면 진입/새로고침 때 필요한 데이터를 요청합니다. Supabase Cron이 매일 한국 시간 오후 8시(UTC 11시)에 지연 가능한 급여·이자·통계 큐를 실행하도록 스키마를 준비했습니다. 구매 RPC는 잔액과 재고를 DB 트랜잭션으로 즉시 확인합니다.

## 로컬 실행

Node.js 20.9 이상이 필요합니다.

~~~bash
npm install
npm run dev
~~~

브라우저에서 http://localhost:3000을 열면 가짜 데이터로 데모를 사용할 수 있습니다. .env.example은 선택적인 Supabase 설정 안내입니다. DB 연결 전에도 UI 데모를 사용할 수 있습니다.

## Supabase 데이터베이스 준비

1. Supabase 프로젝트를 만들고 SQL Editor에서 supabase/migrations/0001_schoolnation.sql을 실행합니다.
2. 운영 전에는 교사/학생 계정 생성과 클래스 구성원을 원자적으로 등록하는 인증 프로비저닝 흐름을 구현합니다.
3. .env.example을 복사해 .env.local을 만들고 URL 및 공개 anon 키를 설정합니다. 비밀 키는 서버에서만 사용하고 저장소에 올리지 마세요.
4. 테스트 학급에는 실제 학생 정보 대신 가짜 이름만 넣으세요.

마이그레이션은 classes, class_members, class_groups, accounts, ledger_entries, shop_products, owned_items, class_features, queued_jobs, audit_events 테이블과 학급 경계 RLS를 만듭니다. 예시 UI의 로컬 데이터와 DB 데이터는 아직 연결되지 않았습니다.

## 원장과 배치 처리

- 계좌 잔액은 음수가 되지 않게 DB 제약 조건으로 보호합니다.
- purchase_product RPC는 구매자 계좌와 재고 행을 잠그고 잔액·재고·원장·보유 아이템을 한 트랜잭션으로 반영합니다.
- queued_jobs는 멱등 키를 보유합니다. job:<id> 키가 원장에 중복 반영되지 않게 합니다.
- 매일 20:00 KST에 기한이 된 예약 작업을 실행합니다. 사용자가 직접 실행하는 구매/송금은 대기시키지 않습니다.
- 로컬 DB에서는 Supabase CLI/SQL로 select public.process_due_jobs(100);을 수동 실행할 수 있습니다.
- 실제 연결 시 재시도 횟수, 실패 사유와 완료 결과가 queued_jobs와 audit_events에 남습니다.

## 보안과 개인정보

- 개발 예시는 가짜 이름과 가짜 거래만 포함합니다.
- 모든 업무 테이블은 class_id를 기준으로 학급을 나누고 RLS를 켭니다.
- 브라우저는 구매·계좌 금액을 직접 쓰지 않으며, DB 함수에서 역할/잔액/재고를 검사하도록 설계합니다.
- 서비스 역할 키를 브라우저 코드나 공개 저장소에 넣지 마세요.
- 학생 글을 외부 AI로 전송하는 기능은 이 버전에 없습니다.
- 계정 삭제나 활동 삭제 UI는 아직 없습니다. 운영판에서는 복구 가능 보관과 감사 기록 정책을 먼저 마련합니다.

## 배포

GitHub revernus-dev/SchoolNation을 배포 플랫폼에 연결하고 npm run build를 빌드 명령으로 사용합니다. 실제 계정/DB 연동은 위의 미완료 항목을 연결한 뒤 활성화해야 합니다. Supabase Free는 프로젝트당 500MB DB 등의 제한이 있으며, 낮은 사용량이 일주일 이어지면 프로젝트가 자동 일시 중지될 수 있습니다. 실제 학급 운영에는 가동률과 백업 요구사항을 확인하고 적합한 플랜을 선택하세요.
