# SchoolNation

아이들과 함께 학급의 약속과 경제를 운영하는 반응형 웹앱입니다. 기능 아이디어만 참고해 독자적인 화면과 구성으로 만들었습니다. 요금제 및 결제 기능은 포함하지 않습니다.

## 로컬 실행

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

현재 UI는 가짜 샘플 데이터를 사용하는 데모입니다. 실제 학급 데이터 사용 전에는 인증 및 데이터베이스 연결을 구성해야 합니다. 데이터베이스 기반은 `supabase/migrations/0001_schoolnation.sql`에 준비되어 있습니다.

자세한 실행, 설정, 배포 안내는 이후 파일 업로드 과정에서 이 문서를 보강합니다.
